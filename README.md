# 📚 Library Management System

A simple **console-based Library Management System** built using **C**.

### ✨ Features

* ➕ Add books
* 📖 View all books
* 🔍 Search by Book ID
* 🗑️ Delete books
* 💾 File-based storage

### 🛠️ Concepts Used

**C • Structures • Arrays • Functions • File Handling**

### ▶️ Run


gcc library_management.c -o library
./library
